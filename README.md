# 🛡️ Fraud Radar
> **Paste a stock tip. Know in seconds if it is a scam.**

Built for the **Sangyan Hackathon** (Investor Resilience track, IIT BHU with SEBI and NSDL).

---

## 📌 Overview
Retail investors, especially in Tier-2 and Tier-3 cities, are frequently targeted by scam stock tips on Telegram and WhatsApp promising guaranteed profits. **Fraud Radar** is a zero-friction web tool where users paste an unsolicited tip and instantly receive:
- A **Deterministic Risk Score** (0–100)
- **Extracted Red Flags** (unrealistic returns, urgency, unregulated UPI payments)
- A **Plain-Language Explanation** generated by an LLM
- **Direct Next Steps** (verify SEBI credentials, lodge a complaint on SCORES, or call 1930)
